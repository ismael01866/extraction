import { BaseContainer, CodeContainer } from '@/app/components';
import { Code } from '@/app/components/code';

# Accents

Accents provide visual emphasis and can be applied to components to enhance their visual appeal.

## Positioning

Use the `decoration-border-{position}` class to adjust the position of the border decoration. Values include `top`, `bottom`, `start` and `end`.

<br />
<section>
  <BaseContainer>
    <Flex className='gap-4'>
    {['decoration-border-start', 'decoration-border-end', 'decoration-border-top', 'decoration-border-bottom',].map((accent, index) => {
      return (
        <Box key={index} className={`p-2 ${accent} variant-outline text-sm rounded-none`}>
          {accent}
        </Box>
      );
    })}
    </Flex>
  </BaseContainer>

  <CodeContainer>
    <Code>
      {[
        `<Box className='p-2 variant-outline decoration-border-start' />`,
        `<Box className='p-2 variant-outline decoration-border-end' />`,
        `<Box className='p-2 variant-outline decoration-border-top' />`,
        `<Box className='p-2 variant-outline decoration-border-bottom' />`,
      ].join('\n')}
    </Code>
  </CodeContainer>
</section>

## Coloring

By default, accents will inherit the palette color of the parent component, but you can use the `border-{position}-{color}` class to set a specific color for the accent.

<br />
<section>
  <BaseContainer>
    <Box className={`p-2 variant-outline w-48 decoration-border-start border-s-success text-sm rounded-none`}>
      Neutral Box
    </Box>
  </BaseContainer>

  <CodeContainer>
    <Code>
      {[
        `<Box className='p-2 variant-outline decoration-border-start border-s-success' />`,
      ].join('\n')}
    </Code>
  </CodeContainer>
</section>

## Custom Width

By default, decoration accents have a width of `3px`, but the utilities support custom widths. Value supports spacing scale steps, length, or percentage. Examples: `decoration-border-start-4`, `decoration-border-start-[4px]`, `decoration-border-start-[4%]`.
