## Extra Palettes

To access the `accent`, `success`, `error`, `info`, and `warning` palettes include the extra-styles file in your main CSS:

```css
/** main.css */
@import 'tailwindcss';
@import 'extraction-ui/styles';

@import 'extraction-ui/extra-styles';
```

You now have access to the full suite of colors.
