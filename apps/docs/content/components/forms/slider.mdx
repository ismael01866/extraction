## Controlled

Use the `value` and `onValueChange` props when you need to control the value externally.

<Usage
  components={{
    usage: <SliderControlledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`const Example = () => {
    const [value, setValue] = useState([50]);
    return (
        <Slider className="w-40" value={value} onValueChange={setValue}>
        <Slider.Track>
          <Slider.Range />
        </Slider.Track>
        <Slider.Thumb aria-label="slider thumb" />
      </Slider>
    );
  };`}
/>

  --ex-slider-size-md: calc(var(--spacing) * 1);
