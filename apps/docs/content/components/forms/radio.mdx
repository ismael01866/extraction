## Controlled

Use the `value` and `onValueChange` props when you need to control the value externally.

<Usage
  components={{
    usage: <RadioControlledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`const Example = () => {
    const [value, setValue] = useState('option-1');
    return (
      <RadioGroup value={value} onValueChange={(value) => setValue(value)}>
        <Radio>
          <Radio.Control value="option-1" id="r1-c">
            <Radio.Indicator />
          </Radio.Control>
          <Radio.Label htmlFor="r1-c">Option 1</Radio.Label>
        </Radio>
        <Radio>
          <Radio.Control value="option-2" id="r2-c">
            <Radio.Indicator />
          </Radio.Control>
          <Radio.Label htmlFor="r2-c">Option 2</Radio.Label>
        </Radio>
      </RadioGroup>
    );
  };`}
/>

## Uncontrolled

Use the `name` prop to include the value in the form submission.

<Usage
  components={{
    usage: <RadioUncontrolledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`<form
    onSubmit={(event) => {
      event.preventDefault();
      const formData = new FormData(event.currentTarget);
      console.log(formData.get('radio'));
  }}>
    <RadioGroup name="radio" defaultValue="option-1">
      <Radio>
        <Radio.Control value="option-1" id="r1-u">
