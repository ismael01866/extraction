## Controlled

Use the `value` and `onChange` props when you need to control the value externally.

<Usage
  components={{
    usage: <TextareaControlledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`const Example = () => {
    const [value, setValue] = useState('');
    return (
      <Field className="w-64">
        <Textarea
          placeholder="Enter your name"
          value={value}
          onChange={(event) => setValue(event.target.value)}
        />
      </Field>
    );
  };`}
/>

## Uncontrolled

Use the `name` prop to include the value in the form submission.

<Usage
  components={{
    usage: <TextareaUncontrolledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`<form
    onSubmit={(event) => {
      event.preventDefault();
      const formData = new FormData(event.currentTarget);
      console.log(formData.get('textarea'));
  }}>
    <Field className="w-64">
      <Textarea placeholder="Enter your name" name="textarea" />
    </Field>
    <br />
    <Button type="submit" className="palette-neutral variant-surface">
      Submit
    </Button>
  </form>`}
/>
