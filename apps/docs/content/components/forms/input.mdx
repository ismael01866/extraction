## Controlled

Use the `value` and `onChange` props when you need to control the value externally.

<Usage
  components={{
    usage: <InputControlledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`const RatingExample = () => {
    const [value, setValue] = useState('');
    return (
      <Field className="w-64">
        <Input
          placeholder="Enter your name"
          value={value}
          onChange={(event) => setValue(event.target.value)}
        />
      </Field>
    );
  };`}
/>

## Uncontrolled

Use the `name` prop to include the value in the form submission.

<Usage
  components={{
    usage: <InputUncontrolledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`<form
    onSubmit={(event) => {
      event.preventDefault();
      const formData = new FormData(event.currentTarget);
      console.log(formData.get('input'));
  }}>
    <Field className="w-64">
      <Input placeholder="Enter your name" name="input" />
    </Field>
    <br />
    <Button type="submit" className="palette-neutral variant-surface">
      Submit
    </Button>
  </form>`}
/>
