## Controlled

Use the `value` and `onChange` props when you need to control the value externally.

<Usage
  components={{
    usage: <PasswordControlledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`const Example = () => {
    const [checked, setChecked] = useState(false);
    return (
      <Password>
        <Password.Input
          placeholder="Enter your password"
          value={value}
          onChange={(event) => setValue(event.target.value)}
        />
        <Password.Toggle>
          <Password.Icon />
        </Password.Toggle>
      </Password>
    );
  };`}
/>

## Uncontrolled

Use the `name` prop to include the value in the form submission.

<Usage
  components={{
    usage: <PasswordUncontrolledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`<form
    onSubmit={(event) => {
      event.preventDefault();
      const formData = new FormData(event.currentTarget);
      console.log(formData.get('password'));
  }}>
    <Password>
      <Password.Input placeholder="Enter your password" name="password" />
      <Password.Toggle>
        <Password.Icon />
      </Password.Toggle>
    </Password>
    <br />
    <Button type="submit" className="palette-neutral variant-surface">
      Submit
    </Button>
  </form>`}
/>
