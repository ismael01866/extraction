## Controlled

Use the `value` and `onValueChange` props when you need to control the value externally.

<Usage
  components={{
    usage: <SegmentedControlControlledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`const Example = () => {
    const [value, setValue] = useState('Day');
    return <SegmentedControl value={value} onValueChange={setValue} items={['Day', 'Week', 'Month']} />;
  };`}
/>

## Uncontrolled

Use the `name` prop to include the value in the form submission.

<Usage
  components={{
    usage: <SegmentedControlUncontrolledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`<form
    onSubmit={(event) => {
      event.preventDefault();
      const formData = new FormData(event.currentTarget);
      console.log(formData.get('segmented-control'));
  }}>
    <SegmentedControl name="segmented-control" items={['Day', 'Week', 'Month']} />
    <br />
    <Button type="submit" className="palette-neutral variant-surface">
      Submit
    </Button>
  </form>`}
/>
