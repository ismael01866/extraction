## Controlled

Use the `value` and `onValueChange` props when you need to control the value externally.

<Usage
  components={{
    usage: <RadioCardControlledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`const Example = () => {
    const [value, setValue] = useState('option-1');
    return (
      <RadioGroup value={value} onValueChange={(value) => setValue(value)}>
        <RadioCard value="option-1">
          <RadioCard.Indicator />
          <RadioCard.Content>
            <RadioCard.Label>Option 1</RadioCard.Label>
          </RadioCard.Content>
        </RadioCard>
        <RadioCard value="option-2">
          <RadioCard.Indicator />
          <RadioCard.Content>
            <RadioCard.Label>Option 2</RadioCard.Label>
          </RadioCard.Content>
        </RadioCard>
      </RadioGroup>
    );
  };`}
/>

## Uncontrolled

Use the `name` prop to include the value in the form submission.

<Usage
  components={{
    usage: <RadioCardUncontrolledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`<form
    onSubmit={(event) => {
      event.preventDefault();
      const formData = new FormData(event.currentTarget);
      console.log(formData.get('radio'));
  }}>
    <RadioGroup name="radio" defaultValue="option-1">
      <RadioGroup name="radio-card" defaultValue="option-1">
        <RadioCard value="option-1">
