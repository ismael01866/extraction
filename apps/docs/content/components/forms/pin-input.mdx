## Controlled

Use the `value` and `onValueChange` props when you need to control the value externally.

<Usage
  components={{
    usage: <PinControlledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`const Example = () => {
    const [value, setValue] = useState('');
    return (
      <PinInput placeholder={'○○○'} value={value} onValueChange={setValue}>
        <PinInput.Field />
        <PinInput.Field />
        <PinInput.Field />
        <PinInput.Hidden />
      </PinInput>
    );
  };`}
/>

## Uncontrolled

Use the `name` prop to include the value in the form submission.

<Usage
  components={{
    usage: <PinUncontrolledExample />,
    wrapper: Wrapper,
  }}
  serializedCode={`<form
    onSubmit={(event) => {
      event.preventDefault();
      const formData = new FormData(event.currentTarget);
      console.log(formData.get('pin-input'));
  }}>
    <PinInput placeholder={'○○○'} name="pin-input">
      <PinInput.Field />
      <PinInput.Field />
      <PinInput.Field />
      <PinInput.Hidden />
    </PinInput>
    <br />
    <Button type="submit" className="palette-neutral variant-surface">
      Submit
