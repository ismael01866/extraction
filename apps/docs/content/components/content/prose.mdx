## Installation

In order to use the Prose component, you need to install the Tailwind CSS Typography plugin:

```bash
pnpm add -D @tailwindcss/typography
```

Add the Tailwind Prose styles to your main CSS file:

```css
/** main.css */
@import 'tailwindcss';
@plugin '@tailwindcss/typography';
```
